# OpenWrt для TL-WR840N v4: USB + дві USB-вебкамери + меню «Вебкамери»

Один проєкт збирає і OpenWrt 19.07.10 (за замовчуванням, `v19.07.10`), і 24.10 (`openwrt-24.10`).
Для 19.07 використовується `config.19.07.seed`, для інших версій `config.seed`.

## Збірка
1. Залийте вміст папки в репозиторій GitHub (разом з `.github/`).
2. Actions -> Build OpenWrt TL-WR840N v4 -> Run workflow, поле: `v19.07.10`.
3. Artifacts: `sysupgrade.bin`, `factory.bin` (для 19.07) або `tftp-recovery.bin` (для 24.10), `SHA256SUMS`, `config.used`.
   У лозі останнього кроку видно розмір `sysupgrade` відносно ліміту 7808 КБ.

## 19.07.10: що відрізняється
- Немає `v4l-utils` у feeds 19.07 (є лише `libv4l`), тому `v4l2-ctl` недоступний. Яскравість та інше задаються у меню «Вебкамери».
- Немає `tftp-recovery.bin`: є `factory.bin`. Для TFTP-відновлення завантажувач може потребувати додаткового відступу (в 24.10 його додає збірка).
- Не відновлюйте конфіг, збережений з 24.10: у 19.07 інший фаєрвол (fw3 замість firewall4). Прошивайте з `-n` і налаштуйте заново.
- Збірка 19.07 на сучасних серверах GitHub може впасти на вихідних інструментах: це стара версія. Якщо так, пришліть лог.

## Меню
`files/usr/lib/lua/luci/controller/cams.lua` реєструє пункт меню на 19.07, `files/usr/share/luci/menu.d` на 24.10.
